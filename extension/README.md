# PointTalk for Grok Bot

Pick any page element (or a parent), add an optional note, copy a structured pack to the clipboard, paste into Grok Bot. Faster and lighter than screen captures.

Works in **Brave** and other Chromium browsers (Chrome, Edge). Breakdance post/node ids are included automatically when the page uses Breakdance; otherwise you still get URL, CSS path, and layout hints.

## Install (unpacked)

1. Keep this `extension` folder somewhere permanent (don’t delete it after loading).
2. Open `brave://extensions` (or `chrome://extensions`).
3. Turn **Developer mode** on.
4. **Load unpacked** → select this `extension` folder.
5. Optional: `brave://extensions/shortcuts` → confirm **Alt+Shift+G** (⌥⇧G on Mac).

## Use

1. Open a normal webpage tab (not `brave://` or the extensions page).
2. Press **⌥⇧G** / **Alt+Shift+G**, or click the toolbar icon.
3. Click an element. Use parent controls if you need a larger chunk.
4. Add an optional note → **Copy for Grok Bot** (or ⌘/Ctrl+Enter).
5. Paste into Grok Bot chat.

## Privacy

The extension only runs when you trigger it on the active tab. It copies text you chose to the clipboard; it does not send data to a server.

## Name

**PointTalk** — point at anything on screen, hold a key, and talk to your Grok Bot agents.
