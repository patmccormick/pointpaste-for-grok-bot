PointTalk for Grok Bot

Pick a page element, add a note, copy a pack, paste into Grok Bot — without burning disk on screenshots.

  1. Keep this extension folder somewhere permanent.
  2. Open brave://extensions (or chrome://extensions).
  3. Turn Developer mode on.
  4. Load unpacked → choose the extension folder.
  5. Shortcuts: confirm ⌥⇧G / Alt+Shift+G.

On a real page tab: shortcut or toolbar icon → click element → optional note → Copy for Grok Bot → paste in chat.
